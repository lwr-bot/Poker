# 后续路线与完成状态

## 已落地

- 现代 CMake、分层目录和旧教程基线隔离。
- 纯 C++17 德州扑克领域引擎及穷举/属性测试。
- 长度帧、Protobuf、幂等序号、限流、心跳、超时和断线快照。
- Muduo 服务适配器、房间单写者执行器和阻塞存储线程池。
- Argon2id、MySQL 账户/钱包/牌局仓库、预处理 SQL 与事务退款。
- Redis 节点注册、全局桌号、负载选择、房间归属和加入凭证。
- 单实例与大厅 + 双游戏节点 Compose。
- 健康检查、Prometheus 指标、连接压测与 libFuzzer CI。
- Qt Quick 客户端第一版。

## 仍需在 Ubuntu 完成的验收工作

1. 用 Docker 构建完整 Muduo/Protobuf/MySQL/Redis 服务并修正平台依赖差异。
2. 运行 MySQL、Redis 与双节点集成测试，补自动化故障脚本。
3. 为领域目标接入覆盖率报告并确认不低于 85%。
4. 在目标机器实际运行 500 个合法活跃牌桌机器人并保存结果。
5. 在固定 2 核 4 GB 环境运行 30 分钟，提交原始 JSON、Prometheus 截图和分析。
6. Qt 客户端补充动画和 TLS，并在 Ubuntu/Windows 进行自动重连与多平台验证。
7. 录制 2～3 分钟演示：全押边池、断线重连、双节点分配、节点停止与退款。
